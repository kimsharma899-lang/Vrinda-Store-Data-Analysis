

An interactive **Microsoft Excel dashboard** designed to analyze Vrinda Store's sales performance, customer behavior, product performance, and sales channels.

## Dashboard Preview

![Vrinda Store Dashboard](dashboard.png)

##  Project Objective

The objective of this project is to transform raw sales data into meaningful business insights using **Excel-based data analysis and visualization**.

##  Analysis

- Sales & Order Trends
- Men vs Women Sales
- Age & Gender Analysis
- Top 5 States by Sales
- Order Status Analysis
- Sales Channel Performance
- Product Category Analysis

##  Tools & Techniques

**Microsoft Excel**  
Pivot Tables • Pivot Charts • Slicers • Data Cleaning • Data Visualization

##  Key Insights

- Women contributed **64%** of purchases.
- **March** recorded the highest sales.
- **Maharashtra, Karnataka, and Uttar Pradesh** were among the top-performing states.
- The **Adult age group** was the largest contributing segment.
- **Amazon, Flipkart, and Myntra** were the leading sales channels.

##  Business Recommendation

Focus on **women aged 30–49** in high-performing states and strengthen promotions through major channels such as **Amazon, Flipkart, and Myntra** using targeted discounts, offers, and campaigns.
